# Notepad

A simple text editor written in Rust, built with [egui/eframe](https://github.com/emilk/egui) and [rfd](https://github.com/PolyMeilex/rfd) for native file dialogs.

**Download:** the latest Windows installer (`.msi`) is on the [Releases](https://github.com/thomas3577/notepad/releases) page.

## Features

- Minimal UI: the menu bar is hidden; press Alt to show it, or use the ☰ button in the status bar
- Tabs: open several files at once (Ctrl+N new tab, Ctrl+W close, Ctrl+Tab switch, middle-click closes)
- Session restore, like Windows Notepad: closing the window keeps all tabs, including unsaved changes and Untitled tabs, and the next start brings them back (also window size, zoom, word wrap)
- One window: starting Notepad again (e.g. Explorer "Open with") opens the file as a new tab in the running Notepad
- New, Open, Save, Save As; saving is crash-safe (temp file + rename)
- Line numbers (correct with word wrap)
- Word wrap on/off (View menu)
- Text zoom (Ctrl+Plus/Minus/0, Ctrl+mouse wheel)
- Status bar: line, column, zoom, encoding, line ending
- Find & Replace (Find Next, Replace, Replace All), case-insensitive by default ("Match case" option)
- Encodings: UTF-8, UTF-8 with BOM, UTF-16 LE/BE, ANSI (Windows-1252)
- Line endings: CRLF and LF are detected and kept on save
- Opens files via Explorer "Open with", the command line, or drag & drop onto the window or the exe;
  a file name that does not exist yet starts a new document saved under that name
- Update check: when a newer release exists, the status bar shows "Update to vX.Y.Z"; one click
  downloads and installs it, and Notepad restarts with all tabs
- Warns when a file contains invalid bytes for its encoding, and before opening very large files

## Build and run

Requires [Rust](https://rustup.rs) (edition 2024).

```sh
cargo run --release
```

The binary ends up in `target/release/notepad(.exe)`.

Tests:

```sh
cargo test
```

## Installer (Windows, .msi)

The MSI installs for the current user only, no admin rights needed:

- `%LOCALAPPDATA%\Programs\Notepad\notepad.exe`
- Start menu entry
- `.txt` association and "New > Text Document" (only if no other per-user `.txt` association exists)
- "Open with" entry

Uninstalling via Settings > Apps removes everything again.

Build (requires [WiX Toolset](https://wixtoolset.org) 7: `dotnet tool install --global wix`):

```powershell
cargo build -r
wix build wix\main.wxs -o target\notepad.msi
```

To make Notepad the default app for `.txt`, choose it once via "Open with > Choose another app > Always".
Windows does not allow installers to set this.

The MSI version is taken from `Cargo.toml` (via the exe's version info).

## Releasing

Bump `version` in `Cargo.toml`, push, then publish a GitHub release with tag `vX.Y.Z`.
The [Release MSI](.github/workflows/release.yml) workflow builds the MSI and attaches it to the release.

## Icon

`assets/icon.ico` is embedded into the exe by `build.rs`; `assets/icon.png` is the window icon.
Both are generated by `assets\make-icon.ps1 -OutDir assets` (then delete `icon-16.png`/`icon-32.png`,
they are only previews).

## Session and privacy

The session is saved every few seconds (only when something changed) and on exit to
`%LOCALAPPDATA%\Notepad\session.ron`, crash-safe (temp file + rename). Window position and size are in
`window.ron` next to it.

**Unsaved text is stored there as plain text**, also text you never saved to a file — like Windows Notepad does.
Delete the folder to clear the session. Uninstalling Notepad does not delete it.

## Encoding detection on open

1. File has a BOM → UTF-8 with BOM or UTF-16
2. Looks like UTF-16 without BOM (zero high bytes) → UTF-16, saved with BOM
3. Valid UTF-8 → UTF-8
4. Otherwise → ANSI (Windows-1252)

The encoding used for saving can be changed in the **Encoding** menu. If the text contains characters that ANSI cannot represent, Notepad offers to save as UTF-8 instead.

## Limitations

- UTF-16 without BOM is only detected for mostly Latin-script text.
- Large files use a lot of memory: egui lays out the whole text (a 5.6 MB file needs about 1.3 GB RAM).
  Notepad asks before opening files over 10 MB, and limits undo history for large files.
